# Português
Projeto desenvolvido para a Unidade Curricular Fundamentos de Programação da Licenciatura Bolonha em Engenharia Mecânica.
O objetivo do projeto foi criar uma aplicação simples para gestão de pedidos de um restaurante, exercitando conceitos fundamentais de programação, como:
- Estruturas de dados (listas, dicionários, arrays)
- Controlo de fluxo (condições, loops)
- Funções e modularização

Este projeto permitiu aplicar os conceitos teóricos aprendidos em aula de forma prática, preparando o estudante para desafios de programação em projetos futuros.

# English
Project developed for the Programming Fundamentals course in the Bachelor’s Degree in Mechanical Engineering.
The goal of this project was to create a simple restaurant order management application, practicing fundamental programming concepts such as:
- Data structures (lists, dictionaries, arrays)
- Control flow (conditions, loops)
- Functions and modularization

This project allowed the student to apply theoretical concepts in practice, providing experience that prepares for programming challenges in future projects.
